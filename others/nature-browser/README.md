# Nature Browser Ultimate 🌿🚀

Nature Browser is a premium, Firefox-powered (GeckoView) mobile-first browser designed for researchers, developers, and power users who demand intelligence and privacy.

## ✨ Ultimate Features

### 🔐 Uncompromising Privacy
- **GeckoView Engine:** Built on Mozilla's Gecko engine, providing standard-compliant rendering and robust tracking protection.
- **Biometric Private Mode:** Sandboxed sessions that erase history, cookies, and cache on close.
- **Native VPN:** Integrated privacy tunnel for secure browsing on public networks.

### 🧠 Page Intelligence
- ** Nature AI Insights:** Instant summarization and key-takeaway extraction using Google Gemini.
- **Deep Analysis:** Pro-level SEO, performance (LCP, FID), and accessibility auditing in one tap.
- **Readability Engine:** Transmutes cluttered websites into distraction-free reading environments.

### 📥 Media & Page Archiving
- **Social Media Sniffer:** Batch-download profiles, images, and high-quality videos from major social platforms.
- **Universal Export:** Port any page to **Markdown**, **PDF**, or **MHTML (Web Bundle)** for offline research.
- **Pause & Resume:** Advanced download queue with persistent state syncing across devices.

### 🎨 Personalization
- **Organic Design System:** Select from Earth, Forest, Water, or Sand themes with fluid dark-mode transitions.
- **Flexible UI:** Swap address bars between top and bottom, and scale typography to your needs.
- **Productivity Start Page:** Customizable widgets for weather, cloud-sync, and focus.

## 🛠 Tech Stack
- **Frontend:** React 18, Vite, Tailwind CSS, Motion.
- **Engine:** Mozilla GeckoView (Android).
- **Backend:** Firebase (Firestore, Auth, Rules).
- **AI:** Google Gemini Pro.

## 📦 Getting Started
1. **Clone & Install:** `npm install`
2. **Start Dev Server:** `npm run dev`
3. **Build Android:** Check the `.github/workflows` for the automated GeckoView release pipeline.
